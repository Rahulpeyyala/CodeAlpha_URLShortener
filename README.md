
# 🔗 CodeAlpha URL Shortener

A simple URL Shortener developed as part of the **CodeAlpha Backend Development Internship**.

## 📌 Project Description

This project converts a long URL into a unique short code.

When a user opens the short URL, the application redirects them to the original long URL.

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## ✨ Features

- Accepts long URLs
- Generates unique 6-character short codes
- Stores URL mappings in SQLite
- Redirects short URLs to original URLs
- Provides a simple web interface
- Provides a REST API endpoint
